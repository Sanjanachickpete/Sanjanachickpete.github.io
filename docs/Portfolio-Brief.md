## Featured Projects

### ASTRA — Autonomous Space Task Recognition Assistant

**Hackathon project concept | SIH Problem Statement 26174**

ASTRA is a concept for AI-based human activity recognition during astronaut
onboard experiments. It aims to recognize activities, validate experiment
procedures, identify skipped or out-of-sequence steps, and provide voice
guidance. The proposed concepts include human activity recognition (HAR), pose
estimation, object detection, lightweight AI, edge AI, and procedure
validation. This is a project concept, not a deployed or completed system.

### HEALTHIFY_IQ — Ingredient Safety Checker

**Website concept | “Smarter choices. Healthier lives.”**

HEALTHIFY_IQ is a website concept to help users understand ingredients in
personal care and household products. Planned features include ingredient
search, a barcode lookup concept, simplified ingredient explanations, and
colour-coded safety information. It is a concept, not a completed product.

### VAANI — Smart Home Assistant

**IoT smart home automation concept/prototype**

VAANI explores smart home automation using components including an
ESP32/ESP8266, relay, DHT11 sensor, and model house. It is a concept/prototype,
not a completed or deployed system.
