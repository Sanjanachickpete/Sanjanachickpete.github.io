Complete each **What changed?** section after comparing the relevant versions.

## 1. Initial Website Generation

### Prompt purpose

Generate the first portfolio website from the portfolio brief.

### Summary of instructions

Use the provided education, projects, coding journey, skills, and career goal
as the source of truth. Create a responsive website with a dark-purple theme,
the requested portfolio sections, and an interactive 2D/3D toggle. Keep the
website in a single root `index.html` file.

### Summary of instructions

Improve creativity, the hero composition, typography, spacing, project cards,
gradients, and overall visual layout. Keep the design elegant and clean, and

## 3. Content Refinement

### Prompt purpose

Review the website against `docs/Portfolio-Brief.md` for completeness and
accuracy.

### Summary of instructions

Check education, featured and academic projects, coding journey, skills,
career goal, and contact details. Remove SWAP and any unsupported achievements,
statistics, internships, certificates, experience, completed-project claims,
or fake links. Clearly label concepts, hackathon work, prototypes, and academic
projects.

_To be completed by comparing the website before and after this prompt._

## 4. Functionality Refinement

### Prompt purpose

Perform a final quality review of interactions, responsiveness, readability,
and visual consistency.

### Summary of instructions

Check navigation, buttons, project cards, GitHub and LinkedIn links, the mobile
menu, and responsive layout. Test that 2D mode is flat without tilt or
perspective and that 3D mode adds subtle depth and gentle hover effects. Avoid
heavy effects on mobile and fix any errors or broken interactions.
