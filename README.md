# Sanjanachickpete.github.io

This repository is for a college AI portfolio activity and will also host a
personal portfolio website through GitHub Pages. The portfolio website has not
been created yet; `index.html` is an empty starting point.

## Repository contents

- `index.html` — root entry point for the future GitHub Pages portfolio.
- `docs/Portfolio-Brief.md` — place to collect personal information, education,
  projects, coding journey, skills, and career goal.
- `docs/Prompt-Log.md` — record the initial AI prompt, refinement prompts, and
  what changed after each prompt.
- `docs/Reflection.md` — final reflection for the activity.
- `assets/` — images and other assets for the future portfolio.

Add only information and links that you have verified. Fill in the activity
documents as the work progresses.
